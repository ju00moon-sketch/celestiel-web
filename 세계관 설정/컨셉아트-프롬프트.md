# 컨셉아트 생성 프롬프트

설정집의 SVG 컨셉 패널 7장을 실제 원화로 교체할 때 쓰는 이미지 생성 프롬프트.
미드저니 기준으로 작성했으며 DALL·E, Stable Diffusion 등에서도 그대로 사용 가능.

## 공통 규칙

- **비율**: 패널 자리가 700×240(약 2.9:1)이므로 `--ar 3:1` (미드저니) 또는 21:9 와이드로 생성 후 크롭.
- **공통 스타일 접미사** (모든 프롬프트 끝에 붙임):

```
dark fantasy concept art, painterly matte painting, muted charcoal and near-black palette with antique gold accents, cinematic ultrawide panorama, quiet dread, no text, no watermark --ar 3:1 --style raw
```

- 이미지 생성 모델은 글자를 망가뜨리므로 **텍스트 없는 그림**으로 뽑고, 라벨은 페이지에서 캡션으로 처리.
- 교체 방법: 생성한 이미지를 `세계관 설정/art/` 폴더에 넣고 해당 SVG 패널을 `<img>`로 바꾼다.

## 표지 배너 9부작 — 설정집 6권 + 사이트 3페이지
