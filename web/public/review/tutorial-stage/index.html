튜토리얼 스테이지 — 속도 턴 필드 흐름 (2026-09-29 새벽, 패키지 확인 전)

캄포 비에호 공터에 들어가면 속도 턴 튜토리얼(여주인공 혼자 대 자경단원 목검 대련)이 열리고, 끝나면 결과 창을 거쳐 탐험으로 돌아오며, 다시 들어가면 두 번째 조우가 열리는 흐름을 게임 실행(1280×720)에서 사람 조작 경로로 찍었습니다. 확인 목록은 튜토리얼 실행 9/9, 필드 실행 12/12 통과입니다. 인물·지형은 아직 블록아웃 대역이고, 패키지 확인은 이어서 진행합니다. 일시정지 화면 사진은 개발용 기록 경로가 찍혀 있어 이 페이지에서 뺐습니다.

공터 튜토리얼 — 여섯 단계 안내와 적 공격 박자 줄

내 차례에는 화면 아래 안내 줄이 단계(이동 → 패링 → 회피 → 회피 불가 → 측면·배후 → 헛손질)를 알려 주고, 가리키는 대상(범위·이동 원·이름 상자·[준비 방어]·경직 칸·박자 줄)에 테두리가 붙습니다. 적 차례에는 스킬 바 자리에 박자 줄이 떠서 표식이 판정선에 닿는 순간 키를 누르게 합니다. 한 단계를 두 번 실패하면 다음 단계로 넘어갑니다.

패배 → 재도전

튜토리얼에서 지면 전투 안에서 재도전합니다(사용자 확정). 재도전 뒤 새 시도의 첫 안내가 다시 나옵니다.

승리 → 결과 창 → 탐험 복귀 → 두 번째 조우 → 도주

튜토리얼 승리 뒤 결과 창에서 Enter를 누르면 복귀 지점(공터 트리거 밖, 숲길 위)으로 돌아옵니다. 트리거 밖으로 나갔다가 다시 들어가면 두 번째 조우가 열리고, 일반전에서는 도주할 수 있습니다. 도주한 조우는 처치로 치지 않아 다시 들어가면 새 전투로 열립니다.

이번 캡처에서 찾아 고친 것과 남은 것

  • 고침: 필드에서 속도 턴 전투 화면이 통째로 숨겨지던 결함(보임 조건이 옛 라운드 전투만 봄). 자동 시험은 이 경로를 지나지 않아 놓쳤고, 게임 실행 캡처에서 드러났습니다. 수정 전 실패하는 시험을 붙여 고쳤습니다.
  • 후속 후보: 적이 여럿일 때 적 체력 막대가 의도 이름표 글자를 가로지름 · 패링 단계 판정 글이 강조 테두리 윗선과 겹침 · 이 구도에서 여주인공이 받은 피해 숫자가 뒤쪽 자경단원 머리 옆에 떠서 누가 맞았는지 헷갈릴 수 있음 · 결과 창이 내용에 비해 화면 대부분을 덮음.
  • 확인 필요: 두 번째 조우는 A~E 다섯 명 파티 대 적 넷으로 시작합니다(튜토리얼은 여주인공 혼자). 이야기상 이 구성이 맞는지 확인이 필요합니다.
  • 미검증: 패키지 실행, 박자 소리·키 안내 음성, 실제 캐릭터 모델.
