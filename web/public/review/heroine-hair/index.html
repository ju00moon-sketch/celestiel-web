여주인공 헤어·얼굴 작업 비교 (2026-09-27~28)

3D 아트 담당의 작업 비교판을 최근 것부터 모았습니다. 확정 얼굴은 모든 판에서 그대로이고, 헤어·목·손목만 바뀝니다. 체형(골반·엉덩이) 작업은 옷을 입힌 판이 나오면 따로 올립니다.

헤어 레퍼런스 v2 첫 판 h1 (2026-09-28, 폰 페이지 v37)

사용자 레퍼런스 v2(뒤통수 X자 꼬임 반묶음·나침반 장식·엉덩이 길이 물결 머리)에 맞춘 첫 판. 아직 레퍼런스와 다른 점이 남아 h2를 만드는 중.

헤어 미세조정 (v36)

정수리 캡 느낌 줄임, 앞머리·옆머리 가닥 다양화, 반묶음 연결부, 뒷머리 층.

헤어 새 생성 방식 (v34)

도면 3방향 부피 목표, 시스루 앞머리, 층진 옆머리, 높은 꼬리로 다시 만든 판. 옛 방식(10차)과 비교.

귀·관자놀이 옛 머리칠 정리 (v34)

머리카락을 숨긴 상태로 귀·관자놀이의 옛 칠 자국을 피부색으로 정리. 변화는 귀·관자놀이에만.

목·손목 수정 (v35)

목 아래 쇄골·근육 음영을 넣고 손목의 고리 모양 턱을 없앤 판. 회색 점검 재질.
