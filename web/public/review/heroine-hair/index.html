3D 아트 담당의 작업 비교판을 최근 것부터 모았습니다. 확정 얼굴은 모든 판에서 그대로이고, 헤어·목·손목만 바뀝니다. 체형(골반·엉덩이) 작업은 옷을 입힌 판이 나오면 따로 올립니다.

얼굴 텍스처 정리 검증 (2026-09-28)

확정 얼굴의 텍스처 정리분(귀·관자놀이 옛 머리칠, 이마·관자놀이 점·얼룩)을 세 갈래로 검증했습니다. ① 형상: 머리 메시 정점 해시가 확정본과 같아 불변. ② 수정 범위: 귀·관자놀이 정리 0.10%, 이마·점 정리 0.18%의 텍셀만 바뀌었고 눈썹·눈·뺨 점 보호 영역 침범은 이마·점 정리에서 0, 귀·관자놀이 정리에서 562텍셀이 보호 판정 안에 들었습니다. ③ 실제 렌더 인상: 같은 장면·카메라·조명에서 텍스처만 세 벌(정리 전 / 귀·관자놀이 정리 / 이마·점 정리)로 바꿔 1800px로 찍어 왼쪽 눈썹 끝·눈꼬리를 2배 확대 비교한 결과, 눈썹·속눈썹·아이라인의 변경 픽셀은 0이고 562텍셀은 눈 보호 타원 가장자리의 관자놀이 피부였습니다. 결론: 되돌릴 것 없음, 현재 텍스처 유지.

헤어 레퍼런스 v2 셋째 판 h3 (2026-09-28)

h2보다 뒤통수 X자 교차가 나아졌지만 레퍼런스와는 아직 거리가 있습니다. 새로 찾은 원인: 뒷머리·묶음 가닥이 뒷목 옷 후드 윗면에 걸려 제자리에서 길이를 다 써 버려, 묶음 가닥 절반이 높이 125~135cm에서 끝납니다(설계는 102~122cm까지). 이 때문에 뒷목에 가로로 부스스한 띠가 생기고 뒷머리가 짧고 성깁니다. 다음 판 h4는 사용자 측 기획 검토(가이드 중심 구조·부위별 제어·원인 분리·앞머리와 뒷목부터 시험)를 반영해, 후드 위로 넘어가는 늘어뜨림 계산과 정수리 부스스함·긴 웨이브를 함께 고칩니다. 모든 판은 옷 입은 렌더이며 확정 얼굴은 그대로입니다.

헤어 레퍼런스 v2 둘째 판 h2 (2026-09-28)

h1보다 잔가닥을 줄이고 정수리를 소용돌이로, 관자놀이를 채우고 옆머리를 넓혔으며, 장식을 귀 위쪽 옆뒤로 옮겨 리본이 오른쪽에 걸립니다. 다음 판(h3)에서 뒤통수 X자 교차를 넓은 띠 두 개로, 정수리 뒤 부스스함·측면 볏·목 뒤 수평 꺾임을 고치고 리본을 톱니 가장자리 천 세 겹으로 바꿉니다.

헤어 레퍼런스 v2 첫 판 h1 (2026-09-28, 폰 페이지 v37)

사용자 레퍼런스 v2(뒤통수 X자 꼬임 반묶음·나침반 장식·엉덩이 길이 물결 머리)에 맞춘 첫 판. 아직 레퍼런스와 다른 점이 남아 h2를 만드는 중.

헤어 미세조정 (v36)

정수리 캡 느낌 줄임, 앞머리·옆머리 가닥 다양화, 반묶음 연결부, 뒷머리 층.

헤어 새 생성 방식 (v34)

도면 3방향 부피 목표, 시스루 앞머리, 층진 옆머리, 높은 꼬리로 다시 만든 판. 옛 방식(10차)과 비교.

귀·관자놀이 옛 머리칠 정리 (v34)

머리카락을 숨긴 상태로 귀·관자놀이의 옛 칠 자국을 피부색으로 정리. 변화는 귀·관자놀이에만.

목·손목 수정 (v35)

목 아래 쇄골·근육 음영을 넣고 손목의 고리 모양 턱을 없앤 판. 회색 점검 재질.
