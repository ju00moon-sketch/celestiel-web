  • 맵: /Game/Maps/L_BattleTest를 열고 PIE를 시작한다(맵은 저장하지 않는다). 사용자 확인은 1920×1080 전체 화면(PIE 새 창 또는 패키지)을 권한다.
  • 콘솔(~)
  • Celestiel.Battle.DebugHUD 1: 상태 줄. 확인이 끝나면 0으로 끈다.
  • Celestiel.Battle.FocusPause 1: 기본값. 포커스 정지를 확인할 때 켜져 있어야 한다.
  • 공격을 바로 직접 받기: `Celestiel.AutoPlay (내부 경로)을 실행한다.
  • S1 1라운드(표적 A, 준비 방어 A2)의 공격 시작 직후에서 정지 상태로 넘어온다. Enter로 재개하면 그때부터 직접 받는다.

  • 이 파일은 자동 테스트 Celestiel.Battle.AutoPlayHandover가 만든다.
  • 계획부터 직접 하기: PIE 시작 화면(계획 화면)에서 명령을 고르고 [실행]을 누른다.

  • 게임 뷰포트 초점: 시작 직후, 버튼 클릭 뒤, 재도전 직후.
  • Slate·뷰포트 두 경로에서 Space·Enter·P가 전달됨.
  • 대응 판정: 30·60·120fps(t.MaxFPS)에서 누름 하나 = 제출 하나, clockMs = atMs.
