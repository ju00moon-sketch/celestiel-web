Layout.Matrix 조합표와 예상 캡처 목록(②-B 준비 초안, 2026-09-28)

  • 코드 편집 없음
  • 근거
  • 엔진 BaseEngine.ini UserInterfaceSettings: UIScaleRule=ShortestSide, 커브 480→0.444·720→0.666·1080→1.0·8640→8.0(선형)
  • 프로젝트 DefaultEngine.ini는 커브를 바꾸지 않았다(FontDPI=72는 UMG 글자에만 쓰인다).
  • 전투 UI는 Slate 글자(96 DPI 렌더)라 글자 em 높이(물리 px) = pt × 4/3 × UI 배율이다.
  • 실측: 14pt 굵은 글 상자 27px(여백 4 포함) = em 약 18.7px(1080p)

  • 안전 시야 비율(1920×1080 기준 63%, 좁은 캔버스는 기록만)
  • 화면 밖 화살표가 화면 안
  • 카드·스킬 바 글자 잘림 없음(측정 폭 ≤ 칸 폭)

2. 글자 크기(물리 em px) — 앞선 보고 정정 포함

  • 정정: 앞서 '720p에서 14pt 글자가 약 9px'이라고 적었는데, Slate 96 DPI를 빼고 계산한 잘못이다.
  • 바른 값: 14pt는 720p 기본 커브에서 약 12.4px이다.
  • 작아지는 것은 10~12pt 글이다(지금 64곳: 10pt 13곳, 11pt 16곳, 12pt 35곳).

  • 기본 커브 그대로면 필수 글은 14pt 이상이 필요하다. 하한 0.8이면 12pt 이상으로 된다.
  • 시험은 글자 요소마다 pt × 4/3 × 배율을 계산해 기준과 대조한다.

3. 예상 캡처 목록(사람 확인용, PIE 창 크기 지정 실행, 해상도마다 같은 장면)

장면확인
C1 아군 차례 명령행동자·대상 카드, 전술 예고(보스 경로·도착·방향·확정/예상·자물쇠), 타임라인
C2 적 차례 대응(보호 구간)실행 범위 하나, 박자 줄, UI 자리 불변
C3 확대 뒤 화면 밖대상·위협 화살표, 전체 보기 복귀 단추
C4 1인 튜토리얼A와 적만. B~E 칸 없음
C5 5인 + 적 6머리 위 막대 겹침, 이름 숨김 규칙, 다음 위협 표식
C6 행동 결과왼쪽 아래 5줄, 적별 줄
  • 해상도 6종 × 장면 6 = 36장
  • 1920×1080 사용자 배율 1.25·1.5 × C1·C5 = 4장
  • 720p 하한안(0.8) × C1·C5 = 2장
