2. 다시 승인받을 필요 없이 설계서에 반영할 결정

항목반영 기준
속도 턴속도에 따라 차례가 오는 방향을 유지한다. 기존 라운드 흐름을 그대로 되살리지 않는다.
일반전·보스일반전은 다수 적을 고려하고, 보스는 이동하며 패턴을 사용한다. 세부 계약은 확인 후 구현한다.
합동 작전·릴레이속도 턴으로 바뀌어도 핵심 방향을 유지한다. 세계관적 원리·정식 명칭·전용 표현은 별도다.
이동·위치칸 없는 위치 이동, 사거리·시야·구역·아군 거리의 의미를 유지한다. 캐릭터별 이동 거리는 행동 순서용 속도와 구분한다.
예고위치로 피할 수 있는 공격은 아군이 이동을 결정하기 전에 의도를 보여준다. 보스 이동 경로·도착 위치·방향·공격 범위·조준 고정 시점을 표시한다.
카메라역동적인 카메라는 유지한다. 박자 읽기 시작부터 마지막 대응 입력까지 위치·회전·FOV를 안정시키고, 큰 결과 연출은 대응 종료 뒤에 둔다.
파티실제 참가자는 1~5명이다. 없는 슬롯은 명령·표적·생존자·타임라인 계산에 포함하지 않는다.
튜토리얼여자 주인공 한 명과 마을 자경단원 목검 대련을 유지한다. 이동→리듬 패링→저스트 회피→위치 회피 불가·준비 방어→측면·배후→가짜 박 순서의 학습 목적을 보존한다.
임시 A~E시험용 역할이며 정식 직업·종족·캐릭터가 아니다. E의 예약 이관을 정식 캐릭터 설계로 확대하지 않는다.
공간 계획옛 공간 v0.3은 기록으로 보존하고, 속도 턴·다수 적·이동 보스용 공간 v0.4를 작성한다.

계승해야 할 대응 규칙: 피격 캐릭터는 누구나 패링할 수 있고 준비 방어는 우대한다. 패링 키는 타격마다 Q/W/E/R/A/S/D/F 중 결정적 난수로 정한다. 저스트 회피는 Space, 방패 수호 직군의 막기는 Shift 유지다. 엄호는 준비 방어자가 가장 가까운 유효 아군을 자동으로 보호하고, 관통이 아닌 공격을 대신 받는 방향이다. '위치 회피 불가'와 '저스트 회피 불가'를 혼동하지 않는다. 전자는 저스트 회피가 가능하며 미카엘식 선고는 별도 예외다. 회피 불가 연속 사용의 허용 예외는 레이드 3단계다. 프리그의 예고 축소처럼 확정된 특수 예외는 보존하되, 세부 미정인 미래 보스 구현까지 현재 작업에 포함하지 않는다. 측면·배후의 피해·치명타·경직 효과와 입력을 포함한 재현 검증을 유지한다. 수치는 적용된 최신 밸런스 기록을 따른다. 예전 시제품 숫자를 임의로 복원하지 않는다.

3. 앞선 검토에서 정정하는 부분

  • 3.1 예고와 카메라: '새로 도입할 제안'이 아니라 이미 결정 기록에 들어간 요구다. 속도 턴 설계서의 미반영·불명확 문구를 고치는 일로 분류한다. 카메라 효과를 삭제하자는 뜻이 아니라 허용 구간을 구분한다.
  • 3.2 E의 역할: 'E의 정식 스킬 정체성을 정해야 한다'는 표현은 부정확하다. 이번 작업은 기존 임시 예약 테스트 기능을 속도 턴에 어떻게 이관할지 결정하는 것이다. 직업·정식 캐릭터·함정 전문 역할을 자동 확정하지 않는다.
  • 3.3 초기 수치: 기존 규칙 안의 시제품 수치 선정·조정은 총괄 위임 범위다. 새 TurnSpeed의 의미·만료 규칙은 계약 확인 대상이지만, 계약에서 초기 수치 시험을 위임하면 100/130/80 같은 값 변경마다 다시 승인받을 필요는 없다. 현재 v0.2에는 속도 수치가 확인 항목으로 남아 있으므로, 이번 계약에서 위임 범위를 명시한다.
  • 3.4 작업 중단: '모든 구현 보류'로 확대하지 않는다. 이미 승인된 기존 작업·검증·문서 정리와 신규 속도 턴 구현의 계약 확인을 구분한다. 신규 속도 턴 계약은 사용자 확인 뒤 구현한다는 결정은 유지한다.
  • 3.5 기존 시험·기록의 폐기: 옛 공간 문서 보존, 기존 5인 시제품 초기화 금지, 작업 삭제 별도 승인과 관련된 기존 결정을 무시하지 않는다. 옛 실행 경로를 사용하지 않는 것과 파일·테스트·기록을 실제로 삭제하는 것은 구분한다. v4 검증 통과만으로 모든 옛 기록 삭제가 자동 승인됐다고 처리하지 않는다.

4. 여전히 고쳐야 할 항목

R1. 공격 지원의 만료 시점 — 문구 충돌 해결과 계약 확인

현 문구: 대상의 다음 차례 시작에 소멸 / 다음 공격 1회에 소비. 문구대로라면 B에게 준 공격 지원이 B가 공격하기 전에 사라질 수 있다(현재 설계의 반례). 권고안: 유효한 지원 대상 공격에서 소비한다. 미사용 지원은 대상의 다음 차례 종료에 만료하는 안을 우선 검토한다. 보호막·준비 방어·엄호는 각각 목적에 맞는 종료 조건을 따로 쓴다. 사용하지 않은 경우, 다단 공격, 반격, 행동 취소, 대상 사망의 소비 처리도 명시한다. 이 제안은 신규 승인값이 아니다. 최종 계약으로 확인한다.

R2. 경직 파괴 — '한 공격 취소' 계승을 기본으로

승인된 기존 전술 규칙은 경직 게이지가 차면 보스의 다음 공격 하나를 취소하는 기준이다. 속도 턴 문서에는 세 표현이 혼재한다. 권고안: 공격 중이면 진행 중 공격을, 그 밖에는 다음 공격 1회를 취소하는 안으로 정리한다. 현재 공격 취소와 다음 차례 취소를 자동 중첩하지 않는다. 취소된 공격에 해당하는 행동 비용은 한 번만 처리한다. 추가 게이지 후퇴·경직 연장·이동 취소는 별도 효과 또는 확인 항목으로 둔다. '공격 하나'와 '차례 전체'가 동일하지 않은 패턴에서 이동·비공격 행동까지 취소할지는 명시한다. 경직 중 재누적·연속 파괴·회복 시점을 정의한다.

R3. 릴레이 — 기존 연계 조건을 보존하고 시간 단위만 이관

현재 '다음 아군 행동 1회 소비'는 유효하지 않은 행동까지 소비할 수 있게 읽힌다. 생성자 다음 차례 시작 만료는 생성자와 수신자의 속도 차이에 따라 사용 기회를 없앨 수 있다. 권고안: G·M·M+를 하나의 일반 보너스로 합치지 않는다. 기존 효과별 생성자·대상·사용 가능자·거리·생성·소비 조건을 표로 만든다. 회복·대기 등 무관한 행동이 해당 자원을 소모하는지 명확히 한다. 빠른 생성자→느린 수신자 사례를 검증한다. 만료의 기준 사건과 최대 보유 범위는 새 계약에서 정한다. 무기한 보유도 자동 채택하지 않는다. E의 예약을 함정으로 바꾸는 안은 제안으로 남긴다.

R4. 자동 엄호 — 대상 선택 원칙 유지, 차례 단위의 갱신 시점 정의

이미 확정된 '준비 방어·가장 가까운 아군 자동 보호·비관통 공격 대체' 원칙은 유지한다. 속도 턴에서는 준비 방어자가 기다리는 동안 아군과 적이 각각 움직일 수 있다. 계약에서 정할 것: 보호 대상은 준비 방어 확정 때 고정하는지, 이후 재선정하는지 / 대상이 엄호 거리 밖으로 나가거나 쓰러졌을 때 처리 / 타격 직전 강제 이동의 경로·빈 자리·방향 처리 / 이동 중인 보스의 공격 방향과 막기의 정면 조건 / 한 적의 연타와 여러 적의 연속 차례에서 엄호 발동 횟수·집중력 소비 / 미리보기의 엄호 선과 실제 보호 대상이 일치하는지. 이 항목은 수동 대상 선택이나 임의 보호로 바꾸라는 지시가 아니다.

R5. 다수 적의 회피 불가 연속 — 확정 규칙을 조우에도 일관되게 적용

적별 직전 패턴만 검사하면 적 1→적 2→적 3이 회피 불가 공격을 연이어 사용할 수 있다. 권고안: 적별 패턴 이력 외에 조우 수준의 실제 공격 이력도 검증한다. '연속'의 기준은 적의 실제 실행 공격인지, 아군 준비 기회 사이의 공격 묶음인지 명시한다. 취소된 공격·이동만 한 차례·회복만 한 차례가 연속 상태를 해제하는지 명시한다. 허용 예외는 승인된 레이드 3단계 규칙과 구분해 기록한다. 타임라인을 임의로 바꾸기보다 패턴 선택과 조우 구성으로 대응하는 안을 우선 검토한다.

R6. 보스 이동·조준 — 예고에 대한 신뢰 보존

확정 요구에 따라 이동 전 위치→경로→도착 위치·방향→도착 후 범위를 미리 보여준다. 계약에서 정할 것: 장애물·경계에 막혔을 때 실제 도착점과 공격 실행 여부 / 사거리 부족, 대상 사망, 공격 취소, 후속 이동의 처리 / 규칙 기반 표적과 고정 표적, 추적 공격의 구분 / 방향 갱신·고정 시점 / 예측이 변하면 어떤 원인으로 변했는지 표시. Circle을 직선 한 번으로 처리하지 않는다. 경유점 등 실제 경로를 정의하거나 시제품 범위에서 별도 보류한다. 실패 시 몰래 재조준하거나 유리한 공격으로 바꾸지 않는다.

R7. 게이지·시간·시작 배치 — 기술 정정과 시험 항목 분리

기술 정정: Speed 100/150, 시작 Gauge 0, 임계값 1000, 정수 틱으로 다음 차례를 찾는 단순 조건에서 매번 0으로 초기화하면 행동 간격은 10틱/7틱이다. 따라서 빈도 비율은 약 1.43배이며, '1배가 된다'는 설명은 수정한다. 잔여량 보존으로 장기 비율을 유지하자는 결론은 별개로 유지한다. 이미 행동 가능한 참가자가 여럿일 때 0틱 처리와 동률 처리를 검증한다. 비행동자의 준비된 게이지를 잘못 초기화하지 않는다. 추가 계약·시험: TurnSpeed(행동 순서)와 MoveRange(이동 거리)를 분리한다. 자동 연동하지 않는다. 아군 선택 시간·카메라 연출 시간·슬로모션이 규칙상 게이지 진행과 대응 판정을 임의로 바꾸지 않게 한다. 시작 거리 = 적 최대 이동 + 근접 사거리 + 여유 조건은 레벨 초안이다. 전 전투에 필수인 사용자 결정으로 기록하지 않는다. 튜토리얼의 안전 확보와 일반전의 접근 턴 반복을 각각 시험한다. 보스 속도·패턴 길이·경직·아군의 위치 재선택 기회를 함께 시험한다. 임의의 보스 추가 턴은 승인 규칙으로 넣지 않는다.

5. 우선 검증 사례

6. 총괄에게 바로 전달할 수정 지시

  1. 결정 기록을 기준으로 속도 턴·다수 적·보스 이동 설계서를 수정해줘. 이미 결정된 속도 턴 방향, 다수 적 일반전, 이동 보스, 역동적 카메라, 합동 작전·릴레이, 실제 참가자 1~5명, 여자 주인공 1인 자경단원 튜토리얼은 다시 기획 질문으로 올리지 말고 유지해줘.
  2. 2026-09-28 결정에 포함된 공간 v0.4 작성, 아군 이동 결정 전 의도 공개, 보스 이동 경로·도착·방향·조준 고정 표시, 대응 입력 구간 카메라 안정, 실제 플레이 검증 요구는 설계서의 확정 요구로 반영해줘.
  3. 공격 지원이 수신자의 공격 전에 만료되는 문구, 경직 파괴의 현재 공격 취소/다음 차례 취소/게이지 초기화 중첩, 릴레이의 무관한 행동 소비와 속도 차이에 따른 만료 문제는 별도 계약으로 정리해줘. 경직은 기존 승인 기준인 '공격 하나 취소'를 계승하는 안을 우선 두고, 더 강한 제압은 변경안으로 분리해줘.
  4. 자동 엄호의 가까운 아군 보호 원칙과 기존 패링·막기·저스트 회피·치명타·구역 규칙은 유지하되, 속도 턴에서 대상 갱신·효과 지속·강제 이동·자원 소비 시점을 명시해줘. 회피 불가 연속은 다수 적이 실제로 만드는 연속 흐름까지 확인하고, 승인된 레이드 예외와 구분해줘.
  5. A~E는 임시 시험 역할이다. E의 예약 이관을 정식 캐릭터·직업 확정으로 확대하지 마. 함정 대체는 제안으로 남겨줘.
  6. TurnSpeed와 이동 거리를 분리하고, 게이지의 잘못된 계산 예시는 정정해줘. 시작 거리·보스 속도·대응 자원 회복은 시제품 시험과 변경 기록으로 검증하고, 미확정 규칙을 숫자 조정으로 몰래 바꾸지 마.
  7. 문서에는 '사용자 확정 / 위임된 시제품 수치 / 기술 계약 / 확인 대기 변경안'을 구분해줘. 기존 역사적 결정 행은 삭제하지 말고, 현재 유효 기준과 대체 관계를 맨 위에 요약해줘.
  8. 신규 속도 턴 구현은 사용자 확인 뒤 시작한다는 결정을 유지하되, 이미 승인된 작업·검증·문서 정리를 불필요하게 중단하지 마. 옛 모드 미사용과 실제 코드·시험·기록 삭제를 구분하고, 삭제 승인을 검증 통과로 대신하지 마.
  9. 새 제안은 기존 사용자 확정으로 기록하지 말고, 남은 규칙 선택만 한 번에 묶어서 보고해줘.
