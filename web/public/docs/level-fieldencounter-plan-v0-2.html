캄포 비에호 필드 조우 배치안 v0.2(⑥)

2026-09-28 ⑥. v0.1에 대한 총괄 결정은 다음과 같다.

  • 지금은 안 B(공터 조우 3개)를 만든다. 완료했고 S4 후속으로 제출했다.
  • 안 A(남동 들판 F2)는 튜토리얼 흐름을 바꿔야 하므로 사용자 확인 항목으로 올린다.
  • F2 유형은 기습으로 한다.
  • 지형 변경은 ⑤의 지형 재질 Fab 층 작업 뒤에 한다.
  • ②-A 트리거 '잠금' 요청은 안 A 승인 뒤에 한다.

이 문서는 안 A를 전제로 한 설계 초안이다. 지형 변경·코드 요청·게임 데이터 추가는 사용자 승인 뒤에 한다.

0. 지금 상태

  • 안 B 완료: 공터에서 튜토리얼 자경단원 → Normal1 → 기습 순서로 조우 3개를 쓴다.
  • 새 기습 조우 Content/Data/Combat/Encounter_TutorialClearing_Ambush.json: 적 4명이 뒤·왼쪽·오른쪽에서 짧은 거리로 시작한다. 검사 실패 0.
  • 비교 그림 LEVEL_ClearingEncounters_v0.1_figs/ClearingEncounters.png
  • 공터 트리거가 세 조우를 차례로 여는 순서는 ②-A의 EncounterId 작업 때 넣는다.
  • 안 A: 사용자 확인 대기(아래 1절).

1. 사용자에게 여쭐 것(안 A)

  • 내용: 튜토리얼 공터 전투를 이긴 뒤 곧바로 숲길(EX_W)로 끝내지 않고, 마을로 돌아와 남동 들판에서 선택 전투(기습)를 할 수 있게 흐름을 바꿀지.
  • 이유
  • 설계 v0.3.1 S4의 '필드 조우 2~3곳'을 채울 수 있는 유일한 새 자리다(v0.1 계산).
  • 기습을 공터와 다른 들판 지형에서도 시험할 수 있다.
  • 바뀌는 것
  • 튜토리얼 흐름: 끝 지점(EX_W)은 그대로 두고, 그 전에 자유 탐험을 허용한다.
  • 들판에 평탄 자리를 만든다(지형 타일 4개).
  • 새 전투 자리 1곳을 더한다(무대·진행자, 장애물 5개, 트리거, 미끼 소품).
  • 안 하면: 공터 한 곳의 조우 3개(안 B)로 시험을 이어 간다.

2. 자리

  • 무대: 중심 월드 (−5400, 2400), 바닥 z −70, 요 90°. 전장 로컬 +X가 월드 동, +Y가 월드 남이다.
  • 아군은 길 쪽(서)에서 들어와 동쪽을 본다.
  • 거리: 물체 여유 22.0m, 입구 길 R_S 가장자리에서 24m, 시작 자리에서 30.5m, 공터에서 60.8m.
  • 평탄 구역
  • 평탄 원 15m + 비탈받이 8m이고, 타일 Terrain_0_2·0_3·1_2·1_3에 걸친다.
  • 비탈받이 끝이 길 동쪽 가장자리 약 1m 앞에서 멈춘다. 바퀴 자국과 M01 데칼 구역에는 닿지 않는다.

5. 트리거·들판 연출

  • 트리거: BattleStartVolume을 무대 중심에 두고 자리 둘레 + 3m(반지름 15m, 상자면 30×30m), 높이 4m, EncounterId CV_Field2_Ambush로 한다.
  • 미끼
  • 로컬 (250, 0) = 월드 (−5400, 2650)에 충돌 없는 작은 소품(버려진 짐 꾸러미)을 둔다.
  • 트리거 안에 있어 다가가면 전투가 시작된다. 살펴보기 지점이 아니다.
  • 무리 대역(FieldGroup)
  • 총괄 결정(2026-09-28): 기습이라 대기 중에도 완전히 숨긴다. 풀 흔들림 같은 약한 단서는 첫 시제품에 넣지 않고, 기획이 '기습 예고 단서'를 정하면 별도 항목으로 한다.
  • 교전이 시작되면 적 시작 자리에 전투 대역이 나타난다.
  • 상태: 잠금(튜토리얼 전, 트리거 끔) → 대기 → 교전 → 처치(트리거 끔) / 도주·패배(폰이 볼륨 밖으로 나간 뒤 다시 켬)
  • '잠금'은 안 A 승인 뒤 ②-A에게 요청한다.

6. 지형 평탄 자리(승인 뒤, ⑤ Fab 층 작업 뒤)

  • 코드(⑥): campo_viejo_terrain.py의 평탄 자리를 하나(공터)에서 목록(FLAT_SPOTS: 중심·평탄 반지름·비탈받이)으로 늘린다.
  • 부조·바퀴 자국·물웅덩이 줄임도 목록 전체에 적용한다.
  • 공터 쪽 결과는 그대로여야 하므로, 공터 영역 높이가 전과 같은지 회귀 시험으로 본다.
  • 순서: ⑤ 지형 재질 Fab 층 반영 → ⑥ terrain_import → terrain_check → create → verify(지면 ±1cm) → capture → walk
