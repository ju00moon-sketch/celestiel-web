G3 캡처 대조 준비 v0.1 — 전장 시험 4·5(⑥)

2026-09-28 ⑥. 총괄 지시("조우 파일·G3 캡처 대조 준비")에 따른 준비물이다. 기준: 설계 v0.3.1의 G3(권고 채택), 전장 계획 v0.4 3절·5절(시험 4·5), S1 규칙 v1.0 10.5절 시험 8.

1. 무엇을 대조하나

  • G3 표시: 경로가 장애물·경계에 닿으면 멈춤 자리 X와 남은 예정 경로 점선을 함께 보인다. 판정은 ②-A, 표시는 ②-B가 만든다.
  • ⑥이 보는 것
  • 캡처의 X·점선이 전장 기하에서 나온 기대값과 맞는가.
  • 시험 5: 미리보기의 X가 실행 뒤 실제 멈춤 자리와 같은가.
  • 범위 밖
  • 시야·사거리 미리보기(시험 4의 나머지)는 ②-A 판정 함수의 단위 시험으로 본다.
  • S1 시험 8의 사례(고정 전 재선정, 선사망, 추적 고정 시점, 사건 순서)는 ②-A 몫이다.

2. 도구: Scripts/Level/g3_capture_check.py(Unreal 없음)

  • 기대값: 전투 공간 JSON과 이동·돌진 경로로 멈춤 자리·간 길이·막은 것·남은 경로를 낸다.
  • 규칙 코드(CombatTactics::ChargeStop, 이동 막힘)와 같은 해석이다. 경계는 정확한 원(중심 거리 ≤ R − r)이고, 막는 장애물과 다른 몸은 몸 반지름만큼 넓힌 외접 16각형이다.
  • 1cm씩 걷는 방식이라 코드(진입 길이 내림 뒤 1cm씩 당김)와 반올림 차이로 ±2cm 안에서 같다.
  • 돌진 멈춤은 코드처럼 장애물·경계만 본다. 이동은 사례에 적은 다른 몸도 막는 것으로 본다.
  • 투영: 진행자 조망(ABattleDirector::MakeOverviewShot)과 같은 식으로 월드 점을 캡처 화소로 옮긴다. 무대 변환, 조망 조작(이동·회전·배율), 16:9 기준 화각의 Hor+ 변환을 반영한다.
  • 겹쳐 그리기: 흰 가는 선 = 계획 경로, 초록 = 기대 간 경로, 자홍 X = 기대 멈춤, 자홍 점선 = 남은 경로. --outline은 장애물 바닥·꼭대기 윤곽과 경계 원을 그려 투영부터 확인한다.
  • 입력: Scripts/Level/g3_cases/*.json(사례 파일). 형식은 도구 첫머리 설명에 있다.
  • 시험: Scripts/Level/tests/test_g3_capture_check.py 4개. 레벨 시험 전체 56개가 통과했다.

사용


python Scripts/Level/g3_capture_check.py Scripts/Level/g3_cases/p2.json --capture 캡처.png --out 대조.png
python Scripts/Level/g3_capture_check.py --arena TacticsArena_P2 --capture 캡처.png --out 확인.png --outline

4. 캡처 요청 조건(②-A·②-B·③)

  • 게임 화면만 찍은 캡처(1920×1080 또는 1280×720). 에디터 창 전체 캡처는 쓰지 않는다.
  • 조망은 기본(전체 보기 Home 뒤)으로 둔다. 조작했다면 로그 camera_overview의 pan_x·pan_y·yaw·zoom을 사례 파일 camera에 적는다.
  • 장면마다 두 장
  1. 아군 이동을 정한 직후, 적 차례 전의 예고 화면(X·점선이 보이는 때)
  2. 적 행동이 끝난 뒤
  • 같은 차례의 사건 로그(돌진 멈춤 좌표와 막은 것 id)

5. 합격 기준

  • 수치: 로그의 멈춤 좌표가 기대값과 ±2cm 안이고, 막은 것 id가 같다.
  • 화면
  • X 중심이 기대 X 투영점에서 바닥 기준 25cm 안이다. 1080p에서 P2 조망은 약 6px, 공터 조망은 약 13px이다.
  • 점선이 기대 남은 경로를 따라간다.
  • 막히지 않는 대조 장면(5a 대조)에는 X가 없다.
  • 시험 5: 미리보기의 X와 실행 뒤 실제 멈춤 자리가 같은 값이다.
