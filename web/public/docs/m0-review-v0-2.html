2. 포지션 추천안의 중복·누락

중복

항목내용영향처리 제안

v0.2 방침대로 역할 이름을 근거로 이 기능을 자동으로 넣지 않는다. 시제품은 기존 15개 스킬로 규칙을 검증하고, 위 기능은 4장의 추가 규칙 후보로 둔다.

한 명이 빠질 때(v0.2 8장의 관찰 질문, 수치표 v0.1 기준 분석)

빠진 역할남는 것무너지는 것
A 수호번개 기본(위력 1) → 사격 강화 → 전하 → 마무리 연계충격 생성, 충격 강화 치유. T01 표적이 체력 높은 다른 사람으로 옮겨감
B 변환모든 기본 행동, 충격 → 치유사격의 강화와 전하 출력이 모두 사라져 검사의 마무리 강화까지 끊긴다
C 사격모든 기본 행동, 충격 → 치유번개 부여의 소비자가 사격뿐이라 술사의 강화 역할이 사라지고, 검사도 전하를 못 받는다
D 마무리번개 → 사격 강화전하가 소비되지 않고 사라짐
E 지원충격 → 번개 연계회복 수단 전부

결론: 한 명이 빠져도 모든 행동이 무효가 되지는 않는다(기본 행동과 방해는 남는다). 다만 B와 C는 서로에게만 연결된 단일 경로라서 둘 중 하나가 빠지면 연계의 대부분이 끊긴다. 설계 의도인지 확인이 필요하다(4장 N6).
