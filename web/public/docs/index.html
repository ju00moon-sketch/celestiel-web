CELESTIEL 개발팀의 기획·설계·검토·결정 문서 전체입니다. 확정된 것과 아직 제안·초안 단계인 것이 함께 있으니 상태 표시를 보고 읽어 주세요. 이 목록은 기획 참고용이며 문서가 갱신되면 다시 올립니다.

개발 진행 현황 요약(2026-09-28)

전투 시스템

  • 반응형 전투 시제품 완성: 라운드마다 계획을 제출하고 실행(아군 선행 → 적 공격 → 대응 박자로 막기·회피·엄호 → 아군 후행). 위치·구역(정면·측면·배후 60°/150°), 경직 게이지, 연계, 엄호 거리, 판정 폭이 규칙에 들어 있다.
  • 캄포 비에호 공터 튜토리얼(여섯 단계: 이동·측면·막기·회피·회피 불가·가짜 박)과 단계별 안내 UI, 조망 거리 3200, 카메라의 인물 가림 회피(시선이 인물 몸 원기둥을 지나면 ±20°/±40° 회피), 탐험 복귀 때 눌린 키와 새로 누른 반대 키를 구분하는 입력 처리, 먼 조망에서 머리 위 타격 수 표시가 주 브랜치에 통합됐다.
  • 모든 전투는 사건·입력 기록으로 다시 재생해 바이트 단위로 같은지 검증한다(기록 회귀 30개).
  • 사용자 결정(2026-09-28): 속도(속공)에 따라 차례가 오는 턴 구조로 바꾸고, 일반 전투는 몬스터 다수 상대, 보스는 전장을 움직이며 패턴을 구사하며, 카메라를 차례마다 움직인다. 통합 설계서 v0.2가 사용자 확인을 기다린다(확인 항목: E의 예약 폐지 뒤 정체성, 경직 파괴 양, 패배·도주, UI 제안값, 시험용 적 3종, 속도 수치).

캐릭터 모델링(여주인공)

  • 얼굴 확정(v4). 그 얼굴을 지키면서 헤어·체형을 다듬는 중. 헤어는 사용자 레퍼런스 v2(뒤통수 X자 꼬임 반묶음, 나침반 장식·리본 오른쪽, 엉덩이 길이 물결 머리)로 다시 만드는 중이며 이마·관자놀이의 옛 칠 자국 정리를 텍스처에 적용했다.
  • 체형은 골반 33.1→37.4cm, 허리 19.2→18.5cm(잘록하게), 엉덩이 두께 17.4→19.5cm, 골반 아래 옆선을 곡선으로 채우고 엉덩이 볼륨 중심을 원래 높이로 둔 판(v2d)까지 왔고, 새 체형 레퍼런스(v3)에 맞춘 v003 후보(허리 약 19.8cm, 골반 유지)를 준비 중이다.
  • 몸은 열네 조각 모듈(머리·팔·손·허벅지·종아리·발 좌우 + 몸통) + 88본 리그로 인계됐고, 게임 안에서 외형을 붙이는 연결 코드 1단계(요청 번호·여섯 검증·한 프레임 원자적 교체·숨김·순간이동 리셋)가 커밋됐다. 옷 분리와 실제 자산 조립은 다음 단계.

레벨 디자인(캄포 비에호)

  • 집 열세 채·예배당·우물·밭·전투 공터 블록아웃, 해질녘 조명(4200K), 흙길 물웅덩이·젖은 흙 재질, 사실풍 소품 1단계(초가·우물·입구 팻말)를 마쳤다. 공터는 전술 튜토리얼용으로 켜져 있다(조망 3200).
  • 다음: 풀·덤불·나무·마을 소품(외부 에셋 라이브러리) 채우기, 성능 측정(카메라 재생 진단 명령 구현 완료, 패키지에서 프레임 시간 측정 예정), 사용자 확인용 캡처.
  • 다수 적·보스 이동 전장 초안: 무대 반지름 일반 12m·보스 15m·큰 보스 18m, 가장자리 띠 4m 비움, 진영 간 거리 규칙, 조우 데이터 파일 방식, 시험용 적 대역 3종(근접·원거리·돌진형).
