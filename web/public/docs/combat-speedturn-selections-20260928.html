2. 추가 조건 원문(계약과 시험에 반영)

  1. B3 재누적 금지만으로 무한 제압 방지가 완료됐다고 보지 마. 아군 5명 뒤 보스 공격이 매번 취소되는 반례를 검증하고, '최대 두 차례에 한 번'이라는 설명은 검증 전 확정하지 마. 별도 면역 등 새 규칙이 필요하면 변경안으로 보고해줘.
  2. F1은 적 차례 시작 고정이므로 고정 전에는 예상, 고정 뒤에는 확정으로 표시해줘. 이미 고정된 위치형 공격을 몰래 재조준하지 마.
  3. F4 대체 패턴은 아군의 마지막 이동 결정 뒤에 새로운 위험 범위나 더 큰 대응 부담을 만들면 안 된다. 안전하게 대체할 수 없으면 해당 적 차례를 대기로 처리해줘. F5의 불리한 패턴 되돌림 금지는 유지한다.
  4. G2는 카메라 채널만 변경하고 전투 이동 경계는 유지해줘. H2 가독성은 실제 720p 출력에서 검증해줘.

4. 담당별 반영 지시

  • ②-A(S1 규칙·계약·기록 v4·튜토리얼 재매핑): 규칙 절 초안을 확정본 v1.0으로 올린다(선택 표 3절 그대로, 조건 1~3을 규칙·시험 사례에 명시). 조건 1: '아군 5명이 보스 뒤에서 매 차례 경직을 쌓아 보스 공격이 매번 취소되는' 반례 시나리오를 시험으로 만들고 결과를 보고한다. '최대 두 차례에 한 번' 같은 빈도 설명은 검증 전 문서에 확정 문구로 쓰지 않는다. 별도 면역 등 새 규칙이 필요하면 구현하지 말고 변경안으로 보고한다. 조건 2: INTENT 사건에 lock 상태(예상/확정)를 실어 UI가 구분 표시하게 하고, 고정 뒤 위치형 공격의 재조준 경로가 코드에 없음을 시험으로 보인다. 조건 3: F4 대체 패턴 선택 시 '아군 마지막 이동 결정 뒤 새 위험 범위·대응 부담 증가 금지' 검사를 넣고, 안전 대체가 없으면 그 적 차례를 대기(사건 기록)로 처리한다. F5 되돌림 금지 유지. 새 규칙 확대 금지.
  • ②-B(S2 타임라인·예고 2단계·예약 결정 화면·적 정보 UI): 조건 2의 예상/확정 표시(점선 '예상' → 실선 '확정', 고정 시점 = 적 차례 시작)를 U-절에 고정. H2① 적용 뒤 실제 720p 패키지 출력 캡처로 필수 글 12px·보조 글 9px 합격선을 검증(편집기 창 캡처로 대신하지 않음). H3 미도입. U11 예약 결정 화면은 C3① 범위.
  • ⑥(S4 전장 v0.4 적용·조우 배치·시험용 적 3종): G1·G3·G4 권고 적용. G2는 경계 벽의 카메라 채널만 무시로 바꾸고 전투 이동 경계(5m 벽)는 그대로 둔다(조건 4). 시험용 적 3종은 블록아웃 임시(I2).
  • ③(S5 검증·패키지): 시험 15건+사례, 전장 시험 6, UI 시험(Layout.Matrix 포함), 조건 1 반례 시나리오, 조건 2 재조준 부재, 조건 3 F4 안전 대체·대기 처리, 조건 4 720p 실제 출력 검증을 완료 조건에 넣는다. 옛 코드 삭제는 하지 않는다(I3).

5. 착수 순서

S1(②-A)이 계약 확정본 v1.0을 먼저 커밋한 뒤 ②-B·⑥이 같은 계약으로 병행한다. 한 작업 트리 규칙(빌드·시험 중 편집 중지, ③ 검토 중 제출 파일 불변, 공유 파일은 총괄 결정으로 한 커밋)은 그대로다. 구현 중 8절 밖의 판단이 필요하면 구현하지 않고 총괄에게 변경안으로 올린다.
