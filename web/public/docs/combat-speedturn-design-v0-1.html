속도 턴·다수 적·보스 이동 패턴 — 설계서 v0.1 (총괄 뼈대, 사용자 확인용)

2026-09-28 총괄. 사용자 결정(같은 날): A = 속도(속공)에 따라 차례가 오는 턴 구조, B = 카메라 권장 세트 그대로, C = 다수 적 일반 전투 설계서 진행 + 보스도 움직이며 공격 패턴을 구사.

이 문서는 총괄 제안 뼈대다. ②-A(규칙)·②-B(UI)·⑥(전장)의 절 초안을 받아 v0.2로 통합한 뒤 사용자 확인을 받고 구현한다. 수치(속도 값·적 수치)는 사용자 기획에서 확정한다.

1. 속도 턴 구조(총괄 제안)

  • 속도 게이지(타임라인): 인물·적마다 Speed(속공)를 둔다. 매 틱 게이지에 Speed를 더하고 1000에 먼저 닿는 쪽이 행동한다(행동 뒤 0으로). 동률은 아군 우선 → 인물 순서표. 빠른 쪽은 같은 시간 안에 더 자주 행동한다.
  • 차례 단위: 한 차례에 한 명이 한 행동(이동+행동은 한 차례 안, 전술 이동 한도는 지금 규칙 유지).
  • 아군 차례: 계획 제출 없이 그 인물의 행동을 고르고 바로 실행한다(대상·구역·이동을 화면에서 지정). 지금의 선행/후행 개념은 없어진다.
  • 적 차례: 그 적의 공격 패턴을 예고(INTENT)한 뒤 실행하고, 대응 박자(막기·회피·엄호)는 그대로 쓴다. 패턴 사이 '회피 불가 연속 금지'는 같은 적 기준으로 유지.
  • 라운드: 타임라인에는 라운드가 없다. 효과 지속·소멸은 '차례 수'로 센다(예: 3차례 뒤 소멸). 기록·재실행(바이트 일치)은 차례 단위 사건으로 다시 정의한다.
  • 시간 표시: 화면 위 타임라인 띠에 다음 8~10차례의 얼굴/적 아이콘을 순서대로 보인다(②-B). 속도가 바뀌면(경직·둔화) 띠가 즉시 다시 정렬된다.
  • 튜토리얼: 6단계 안내는 차례 단위로 다시 매핑한다(②-A·②-B). 옛 계획-실행 튜토리얼 기록은 폐기하고 새 기록을 만든다.

2. 다수 적 일반 전투

  • 적 id 체계(enemy:k), 적마다 체력·경직·구역·예고 범위·Speed. 보스는 '적 1명(큰 몸집·핵)'인 특수 경우.
  • 대상 선택: 아군 차례에 적을 고른다(누르기·Tab 순환). 사거리 선은 적마다.
  • 적 차례마다 예고 범위 하나만 뜨므로(타임라인이라 동시 공격이 없음) 범위 겹침 문제는 사라진다. 대응 박자도 한 번에 하나.
  • 화면: 보스 막대 → 적마다 머리 위 체력·경직 막대 + 타임라인 띠 아이콘. 결과 요약에 적별 줄.
  • 조우: 필드 트리거마다 적 구성 데이터(종류·수·자리). 탐험 화면에 몬스터 무리를 보이게 하려면 진입 때 숨김·처치 상태 유지(⑥ 배치·②-A 상태).
  • 승패: 승리(전원 처치)·패배(아군 전원 전투 불능 → 재도전/마을 복귀, 사용자 결정 필요)·도주(일반 전투만, 실패 확률·사용자 결정 필요).
  • 시험용 적: 블록아웃 대역 2~3종(근접 잡졸·원거리·돌진형)만 개발팀이 두고, 정식 종류·수치는 기획에서 받는다.

3. 보스 이동·공격 패턴

  • 보스는 자기 차례에 이동 + 패턴을 한다: 접근(가까운 인물 쪽으로 걷기), 돌진(지금 BOSS_MOVE 확장), 후퇴 뒤 원거리 패턴, 무대 가장자리 돌기.
  • 패턴 데이터에 이동 규칙을 붙인다: MoveBefore(패턴 전 이동 방식·거리 한도)·FacingRule·MoveAfter(빗나감 뒤 위치).
  • 위치가 바뀌므로 구역(정면·측면·배후)은 매 차례 보스 위치·방향으로 다시 계산한다(지금 규칙 유지).
  • 전장: 보스 이동이 의미 있으려면 무대 반지름·장애물이 필요하다(⑥ 안). 인물 가림 회피 카메라(구현됨)를 보스 이동에도 적용.

4. 카메라(B 그대로)

차례 전환 스윙(아군 차례: 아군 뒤 낮은 앵글 → 적, 적 차례: 적 뒤 → 아군), 행동 인물 어깨 뒤 추적 + 타격 순간 줌, 적 공격 예고 클로즈업 → 박자 줄, 막기 성공 흔들림·실패 낙하감, 결정타·경직 파괴 0.3초 슬로 + 줌, 전투 끝 조망 복귀. 보스 이동 중에는 옆 추적(돌진 캡처 구도).

6. 사용자 확인 항목(v0.2에서 답 요청)

  1. 속도 게이지 방식(1000 채우기)과 동률 규칙 — 총괄 제안대로 가도 되는지.
  2. 아군 차례에 계획 제출을 없애고 즉시 실행 — 동의하는지(전술 미리보기는 남김).
  3. 패배·도주 규칙.
  4. 시험용 적 3종(근접·원거리·돌진형) 임시 사용.
  5. 타임라인 띠 문구·위치, 차례 배너 문구('아군 차례/적 차례' 또는 '우리 차례/적의 차례').
