1. 확인이 필요한 차이

#항목v0.3에 있는 것총괄 제안확인 전 처리제안과 다르게 정하면
X1B 보호막의 지속정밀 실패로 지우지 않는다는 규칙만 있고 지속 기간은 없음라운드 종료 때 사라짐. 매 라운드 새로 계획하는 흐름에 맞고 중첩 규칙이 필요 없음임시 기본값으로 제안대로 동작, 로그에 확인 대기 표시다음 라운드까지 남기면 중첩·상한 규칙이 새로 필요
X2B 보호 지원의 대상예시의 대상은 A아군 1명, B 자신 포함. A가 쓰러진 뒤 B가 표적이 되면 스스로 버틸 수단제한 없음(자신 포함 허용)자신 제외 시 A 사망 뒤 B의 대응 수단이 줄어듦
X3E 공격 지원의 지속과 '공격'의 범위"D의 다음 공격 한 번, 중첩 없음"라운드 종료 때 사라짐. 보스에게 피해를 주는 행동은 모두 '공격'임시 기본값으로 제안대로 동작, 로그에 확인 대기 표시다음 라운드로 넘기면 예약이 항상 유리해지는 문제(K7)가 커질 수 있음

X5예약 결정 때 회복이 유효한 조건"현재 체력·생존을 다시 검증"체력이 가득이면 비활성비활성하지 않고 예상 회복량 0 표시계속 허용하면 효과 없는 선택이 가능
X6E의 회복·공격 지원을 예약 없이 고정 명령으로 쓸 때의 구간없음후행만(역할 '사후 지원'에 맞춤)선행·후행 모두 허용선행 허용 시 보스 공격 전 회복·지원 가능(회복은 최대 체력에 걸려 낭비되기 쉬움)

2. 기술 선택 (게임 규칙이 아님, 참고)

  • 전투 시계는 한 번에 최대 50ms만 나아간다. 프레임이 끊기면 전투가 잠깐 느려질 뿐 입력창을 건너뛰지 않는다(RT-12 원칙과 위험 K2 대응).
  • 모든 계산은 정수로 한다(감소율은 1/10000 단위). 같은 입력이면 어느 PC에서나 같은 결과가 나오게 하기 위해서다.
  • 누름은 누른 시각 그대로 판정하고, 같은 시각이면 타격보다 먼저 판정한다. 어느 타격의 예고에도 속하지 않는 누름과 일시정지 중의 누름은 판정하지 않고 기록만 한다(RT-05, RT-12).
  • 재실행용 입력 로그에는 보스 공격 중의 누름·일시정지·재개를 한 순서대로 남긴다. 거부된 누름까지 같은 결과로 재현하기 위해서다.
