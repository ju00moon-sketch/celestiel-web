캄포 비에호 필드 조우 배치안 v0.1(⑥)

2026-09-28 ⑥. 총괄이 승인한 범위는 배치안 문서(지형 평탄 원 영향 포함)다. 실제 지형 변경은 총괄 결정 뒤에 한다.

기준

  • 설계 v0.3.1의 S4 행 '필드 조우 2~3곳'
  • S4 초안 v0.1 3절(조우 파일 + 트리거는 id만, 무리 대역 FieldGroup, 트리거 상태 전환)
  • 전장 계획 v0.4 1~2절(일반 조우 12m, 장애물·배치 규칙)
  • 튜토리얼 흐름 v0.2(시작 → 팻말 → 우물 → 예배당 → 공터 전투 → 숲길 EX_W에서 끝, 동쪽·북동 출구는 막힘 표시만)

1. 새 전투 자리 하나의 조건

  • 바닥: 전투 12m + 평탄 원 15m(반지름 + 3m) + 비탈받이 8m(지형 도구 ARENA_RAMP)까지 23m 안이 무대 높이와 같아야 한다.
  • 카메라 여유: 나무·충돌 없는 원 20m(카메라 여유 12~20m).
  • 한 높이 구간: 평탄 구역 23m가 바닥 기준 높이 한 구간 안에 들어야 한다(절토·성토 없음).
  • 바닥 기준 높이는 x만의 함수다: 남쪽 x ≤ −1200은 z −70, 마을 −400~1400은 z 0, 북쪽 x ≥ 2450은 z 176, 그 사이는 비탈(북쪽 약 9.5°).
  • 공터와 따로: 공터(F1)의 평탄 18m·비탈받이 26m와 겹치지 않는다(중심 거리 ≥ 49m).

  • 다른 곳이 안 되는 이유
  • 북쪽 z 176 구간: 경계까지 여유가 모자라 23m 평탄 구역이 들어가지 않는다.
  • 마을 z 0 구간: 폭이 18m뿐이고 건물·광장이 있다.
  • 서남쪽: 공터 F1과 숲 띠가 차지한다.

  • (−5400, 3000~4200)도 된다(여유 22~23.3m). 길에서 멀수록 덜 보인다.

4. F2 자리 개요(안 A일 때, v0.2에서 확정)

  • 전투 공간 파일: Arena_CV_Field2.json(가칭). 반지름 1200.
  • 무대 요 90°: 파티가 길 쪽(서, −Y)에서 들어와 동(+Y)을 본다. 전장 좌표의 +X가 월드 +Y다.
  • 장애물: 전장 규칙에 맞춰 새 소품(바위·통나무·덤불)을 둔다. 이동을 막는 것 3~5개, 서로·시작 자리와 5m 이상, V자 배치 금지, 시야 차단은 높이 2~3m. 꾸미기 계획과 맞춘다.
  • 트리거·무리: 자리 둘레 + 3m(15m 원). FieldGroup 무리 대역은 적 시작 자리 근처에 둔다.
  • 조우 유형
  • 기습(권장): 지금 조우 파일이 튜토리얼·일반뿐이라, G4의 세 유형을 모두 한 번씩 시험할 수 있다. 들판의 키 큰 풀(Fab Wild Grass·Uncut Grass)에 숨어 있다가 옆·뒤 짧은 거리에서 시작한다. 검사기의 '불리함 표시' 경고로 확인한다.
  • 일반: 진영 간 4~7m.
  • 지형
  • 평탄 원 15m + 비탈받이 8m를 z −70으로 둔다. 걸치는 타일은 Terrain_0_2·0_3·1_2·1_3이다(파이프라인은 12개를 모두 다시 내보낸다).
  • 비탈받이 끝이 길 동쪽 가장자리 약 1m 앞에서 멈춘다. 바퀴 자국(길 중심 ±75cm)과 M01 구역(x −3600~−1200)에는 닿지 않는다.
  • 코드: 지형 도구의 평탄 자리를 하나(공터)에서 여러 개로 늘린다(campo_viejo_terrain, ⑥). 그 뒤 terrain_import → terrain_check → create → verify(지면 ±1cm 기준에 새 평탄 원 반영) → capture → walk 순서로 돌린다.
  • ⑤ 관계: R3·R5 측정은 패키지(0b6b3af)로 하므로 에디터 맵 변경과 독립이다(총괄 확인). 다만 ⑤의 지형 재질 Fab 층 작업과 같은 지형을 쓰므로 순서를 맞춘다.
  • 시작 화면: F2는 시작 자리에서 북쪽을 보는 화면의 오른쪽(동) 약 30m다. 튜토리얼 동안에는 무리 대역을 숨긴다(위 '잠금' 상태).
