2. 가르치는 순서(라운드 = 단계)

각 단계는 안내 한 줄과 표시 강조로 시작하고, 해 보면 다음으로 넘어간다. 실패해도 피해가 작고 같은 단계를 다시 보여 준다.

  1. 이동: 적이 부채꼴 범위를 예고한다. 여주인공을 범위 밖으로 끌어 옮긴다.
  2. 리듬 패링: 예고된 3연타를 박자 줄에 맞춰 누른다. 키는 Q·W·E·R·A·S·D·F 중 무작위이고, 완벽·성공·실패가 보인다.
  3. 저스트 회피: 곧게 들어오는 돌진을 Space로 딱 맞춰 피하거나, 계획 때 비켜 선다.
  4. 피할 수 없는 공격: 전체 범위 공격은 위치로 못 피하고 패링만 된다. 준비 방어를 고르면 판정 폭이 넓어진다는 것을 보인다.
  5. 측면·배후: 적 옆이나 뒤로 돌아 공격하면 피해·치명타·경직 게이지가 오른다.
  6. 가짜 박(선택): 표식 없이 예고만 반짝이는 박에 누르면 '너무 이른 입력'이 된다.

그다음은 안내 없이 자유 전투로 이긴다. 막기(Shift)는 방패 수호 직군만 쓸 수 있고 여주인공 직군이 미정이라 가르치지 않는다. 엄호·연계는 아군이 있어야 해서 한 명 튜토리얼에서는 뺀다.

3. 튜토리얼 적 후보(세계관에서)

후보모습패턴과 잘 맞는 점세계관만들기
A. 마을 자경단원과 목검 대련(추천)가죽 조끼, 목검·둥근 나무 방패, 수수한 마을 옷(이름 없는 인물)가로 베기 = 부채, 찌르며 돌진 = 관통, 헛손질 = 가짜 박, 연속 내려치기 = 피할 수 없는 연타살생이 없어 카르마와 부딪히지 않는다. 평범한 인간 주인공의 출발과 맞는다사람형이라 여주인공과 같은 Quinn 뼈대와 기본 애니메이션을 쓴다. 가장 빠르다
B. 숲 가장자리의 큰 멧돼지사실적인 짙은 갈색 멧돼지돌진·엄니 휘두르기·땅 구르기가 자연스럽다남쪽 숲의 평범한 짐승이다. 사냥 살생의 뜻은 따로 정해야 한다네발 짐승이라 뼈대·애니메이션을 새로 만들어야 한다(유료 에셋 불가). 가장 오래 걸린다
C. 북쪽에서 흘러든 마족 낙오병잿빛 갈라진 피부, 비대칭 검은 뿔, 낡은 무구무거운 베기·돌진·잿빛 파동세계관을 일찍 보여 준다. 다만 첫 사건·마족 등장 시점이 아직 미정이라 이야기 결정을 앞당긴다사람형이라 A와 비슷하다. 설정 디자인이 먼저 필요하다

추천은 A다. 가르치는 전투에 가장 잘 맞고, 세계관 결정을 앞당기지 않으며, 가장 빨리 사실풍으로 만들 수 있다.

4. 수치와 구현

  • 수치는 튜토리얼 전용 TUT-T v0.1을 새로 둔다(D2 총괄 위임, BALANCE_LOG 기록). 적 체력과 피해를 낮게 잡아 실수해도 끝까지 배울 수 있게 한다.
  • 규칙: CT-P1 전술 규칙을 한 명 참가로 쓴다. 참가 인원 1~5명은 TUT-PLAY-1에서 이미 구현돼 있다.
  • 튜토리얼 적의 패턴 4~5개와 박자표를 새로 정의한다.
  • 단계 진행(안내·다음 단계 조건)은 진행자 쪽에 둔다. 규칙 판정은 그대로 결정적이다.
  • 담당
  • ②-A: 튜토리얼 규칙 세트·패턴·단계 진행
  • ②-B: 안내 UI·강조 표시
  • ⑥: 공터 전투 공간 데이터·배치·카메라 구도
  • 적 모델: ④ 또는 ⑥(외부 3D 생성 도구 실사 사진 → 3D). 여주인공 모델링이 우선이다.
  • 순서: CT-P1 CP-T3(전술 화면 연결)이 끝난 뒤 시작한다 → CP-TUT-T(재현 기록 바이트 일치, 흐름 A 안에서 PIE, 패키지) → 사용자 플레이.
