2. 배치 변경(동선 T01~T09와 전투 공터 규격은 유지)

2.1 지형

  • 방식: 들판 판(Ground_Field)·둔덕 상자·언덕 원뿔을 높이 격자로 만든 지형 외부 3D 생성 도구 한 장으로 바꾼다.
  • 기준값(tutorial_layout)으로 오프라인 계산한다.
  • 격자: 걷는 범위 안 50cm, 밖 2~4m
  • 렌더: Nanite. 충돌: 지형 외부 3D 생성 도구 자체를 걷는 면으로 쓴다(복잡 충돌을 단순 충돌로).
  • 풀·흙·진흙·이끼 비율은 정점 색으로 칠한다.
  • 이 방식을 고른 이유
  • 모두 스크립트로 만들고 되풀이할 수 있다.
  • Landscape는 만들기와 칠하기가 에디터 GUI 도구 중심이다.
  • 사람이 손으로 다듬을 일이 생기면 그때 Landscape로 옮길 수 있다(높이 격자를 그대로 가져감).
  • 높이 규칙
  • 길: 중심선 양쪽 3m 안은 기울기 2% 이하로 매끈하게, 길 중심은 주변보다 5cm 낮게(바퀴 자국 느낌)
  • 시작 분지 바닥: 가운데 20cm 오목
  • 둔덕
  • 지금 상자 자리에 높이 1.2~1.5m, 폭 3~4m의 둥근 둔덕을 둔다.
  • 안쪽 비탈은 45°를 넘겨 오르지 못하게 한다.
  • 보이지 않는 막음 상자는 남겨 T06(막힘)을 지킨다.
  • 들판: 파장 25~40m, 높낮이 ±40cm의 완만한 물결. 길·전투 공터·다리 앞뒤는 평평하게 둔다.
  • 참나무 언덕: 반지름 12m, 높이 1.2m. 모델 흙더미(가운데 1.1m, 반지름 6.5m)와 겹쳐 이어지게 한다. 지금의 보이지 않는 흙더미 충돌은 지형이 대신한다.
  • 전투 공터: 무대 중심 반경 22m 안은 평평하게(Z −70) 둔다. 인물·보스·카메라 금지 영역·바닥 판 규격 그대로
  • 개울: 폭 4m, 바닥 60cm 깊이, 둑 비탈 30°. 물 표면은 들판보다 40cm 아래. 다리 끝 계단이 둑 위에 오게 한다.
  • 숲 능선: 걷는 범위 밖에서 6~15m로 올라가 공터 좌우와 지역 가장자리를 두른다. 보스 뒤 가운데(무대 기준 −24~20°)는 낮게 트인다(배경 규칙 유지).
  • 먼 언덕: 지금 원뿔 자리를 지형 밖 원경 외부 3D 생성 도구로 둔다(걷지 않음).

2.2 흙길·개울·산울타리

  • 흙길
  • 지금 길 점을 그대로 따라 지형 위에 진흙 재질을 칠한다(폭 3.5m + 가장자리 0.5m 섞임).
  • 바퀴 자국·웅덩이는 데칼로 드문드문 둔다.
  • 길 판 외부 3D 생성 도구는 없애고 지형으로 걷는다.
  • 개울
  • 개울 점을 따라 물 표면 외부 3D 생성 도구(폭 4m)를 둔다. 재질은 엔진 기본 기능으로 직접 만든다(깊이에 따른 색, 잔물결 노멀, 가장자리 거품).
  • 물가에 돌·자갈·수초를 둔다.
  • 보이지 않는 둑 벽과 다리 옆 막이는 그대로 두어 T04를 지킨다.
  • 산울타리
  • 지금 상자 자리를 따라 관목을 촘촘히 심는다(높이 1.6~2.0m, 두께 1.5m).
  • 막음은 지금 상자를 숨겨 유지해 T05를 지킨다.
  • 문 옆 틈은 그대로 둔다.
  • 문 동쪽 산울타리 옆(약 x −8900, y +700)에 나무 한 그루를 둔다(장면 3 오른쪽).

2.3 숲·원경

  • 숲
  • 공·원뿔 나무(TREE·BACK)를 실사 나무로 바꾸고, 능선에 무리를 더한다.
  • 공터 비움 반경 20m, 파티 뒤 카메라 통로, 보스 뒤 가운데 빈 방위는 지금 규칙 그대로 둔다. 배치 뒤 카메라 시선·배경 판독 점검을 다시 돌린다.
  • 나무 수 추정: 가장자리·능선 150~250그루, 중경 관목 300~600포기
  • 마을 실루엣
  • 지금 상자(cv_proxy_boxes)를 캄포 비에호 배치 기준값의 집·예배당 자리에 지붕 있는 실루엣 세트로 바꾼다.
  • 박공 지붕 쐐기는 기존 make_roof_wedge를 쓰고, 초가·기와 색 재질을 입힌다. 종탑과 굴뚝 연기(선택)를 더한다.
  • 원경이라 거리 안개에 반쯤 잠기게 한다. 캄포 비에호에 실제 아트가 들어오면 바꾼다.
  • 소품 밑동: 선돌·돌담·수레·이정표·통나무·문 기둥 밑에 풀·이끼·흙을 둘러 떠 보이지 않게 한다.

2.4 배치 뒤 점검(오프라인 → Unreal)

  • 걷기 경로 사전 계산을 지형 높이로 다시 돌린다(점의 발 높이는 지형에서 읽음).
  • 무대 반경 평탄 검사, 카메라 시선·배경 판독(CAM_Default·CAM_React·조망), 한 명 전투 16:9 캡처
  • 걷기 T01~T09. 울퉁불퉁한 땅이라 도착 판정 반경·낙하 높이 설정을 확인한다.
  • 3인칭 키뷰 3곳, 성능(PIE stat unit, 목표 60fps급 프레임 시간)

  • Dress_Target_Start.png: 시작 분지(3인칭 시작, 피치 −15). 둔덕을 낮은 풀 둔덕으로, 진흙 길, 이슬 풀밭, 마을 실루엣, 들판 안개, 금빛 하늘, 숲 가장자리. 참나무는 유지.

D3식생 흩뿌리기(오프라인 규칙: 길·공터·소품 둘레 제외) → FoliageType + AddInstances로 심기맵 생성약 8~9GB반나절~하루
D4조명·하늘·안개·후처리, 키뷰·전투 캡처로 조정캡처 여러 번약 8GB반나절
D5verify·걷기 T01~T09·성능·사람 확인검증·PIE약 8GB반나절
  • 메모리: 무거운 실행은 한 번에 하나이고, 시작 = 예상 최고 + 3GB, 작업 중 2GB 미만이면 중단한다. 식생 수가 많은 D3·D4는 에디터가 커지므로 실측으로 예상값을 고친다.
  • 품질 원칙: 메모리나 시간 때문에 텍스처 해상도·삼각형을 줄이지 않는다. 식생 수는 성능 측정으로 정하고, 모자라면 먼저 묻는다.
  • 전체: 에셋이 들어온 뒤 약 2.5~3일(세션 작업 기준). 에셋이 늦으면 D1·D2(지형·배치·물·조명 일부)를 먼저 한다.

7. 결정이 필요한 것

  1. Fab 에셋: 무료 항목만 쓸지, 유료도 허용할지. 무료 우선이 제안이다.
  2. 지형 방식: 스크립트 지형 외부 3D 생성 도구(제안, 자동화·되풀이 쉬움) 또는 Landscape(손으로 다듬기 쉬움, GUI 작업 필요)
  3. 해 고도: 12° → 8°. 모든 장면의 그림자 길이와 전투 조명이 바뀌며, 전투 판독은 다시 확인한다.
  4. 사용자 컨셉 그림이 있으면 그것을 1순위 기준으로 삼는다.
