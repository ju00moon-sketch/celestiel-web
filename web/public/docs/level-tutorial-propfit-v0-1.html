  • 대안과 버린 이유
  • 통나무를 길이 500 한 토막으로 하면 두께 113 × 126이 된다. 점프 높이(128)와 15cm 차이라 사실상 넘을 수 없는 벽이 되어 '넘거나 돌아가기' 뜻이 사라진다(틈 여유는 63cm로 거의 같음).
  • 참나무를 수관 1100으로 맞추면 높이가 1067로 낮아져, 분지에서 보이는 첫 목표로서 약해진다.
  • 돌담을 길이 300으로 하면 높이 113(가슴 높이)이 된다. 판독 문제는 없지만 '낮은 돌담'과 멀어진다.
  • 문을 높이 180으로 하면 폭 199, 기둥 사이 약 159라 여유가 37cm로 줄어든다.
  • 다리를 폭 400으로 맞추면 길이 980·높이 268로 커져 개울(폭 4m)에 비해 과하다.

2. 교체 단계에서 할 일(⑥, 같은 맵이라 TUT-PLAY-1과 한 번에 하나씩)

  1. 기준값(LEVEL_Tutorial_layout_v0.1.py → 저장소 사본)
  • 다리·문 앞뒤 길 점을 곧게 펴고, 개울 둑 벽 틈을 다리 폭에서 계산하게 한다(지금은 200 조각 단위라 ±200).
  • 산울타리 틈을 문 폭으로, 통나무를 두 토막으로, 돌담 조각 길이·높이를 바꾼다.
  1. 배치 목록: 블록아웃 외부 3D 생성 도구 대신 모델을 쓴다(Model:N 태그 자리).
  • 모델 크기는 같은 비율 배율 하나로 맞춘다. 피벗은 바닥(README)이라 바닥 높이에 놓는다.
  • 다리 데크·통나무 충돌: 걷기·막힘 판정이 모델 곡면에 좌우되지 않게, 블록아웃 모양을 숨긴 충돌로 남기고 모델 충돌은 끄는 안을 기본으로 한다(⑤와 충돌 설정 합의).
  1. 걷기 경로 사전 계산을 새 크기로 다시 돌린다. 막힘 경로(T04~T06)는 그대로다.
  2. 승인된 함께 할 일
  • 작업용 ID 이름표를 게임에서 숨긴다(총괄 승인).
  • TUT-PLAY-1 항목(필드 게임 모드, 무대·진행자, 트리거 3종, 복귀 지점, StartPitch −15, 캄포 비에호 도착 자리)은 그 배정 때 한다.
  1. Unreal: create → verify → capture(특히 다리·문·통나무 근접, 3인칭) → walk. 무거운 실행 기준에 따른다.
  • 시작 조건: 예상 최고 + 3GB 이상.
  • 작업 중 2GB 미만이면 중단한다.

3. 임포트 뒤 확인할 것(⑤·⑥)

  • 문: 열린 문짝이 어느 쪽으로 얼마나 나와 있는지(경계 상자). 통로를 막으면 문짝 방향·자리를 바꾼다.
  • 다리: 난간 위치와 데크 높이(모델 높이 192에 난간 포함 여부). 숨긴 데크 높이를 모델 데크 윗면에 맞춘다.
  • 참나무: 줄기 반지름(충돌 원기둥 크기).
  • 모든 소품: 같은 비율 배율이 ⑤ 임포트 결과와 맞는지(정규화 크기 × 배율 = 위 표).
