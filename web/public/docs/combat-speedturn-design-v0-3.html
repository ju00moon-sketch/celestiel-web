1. 다시 묻지 않고 반영한 사용자 확정

항목반영
속도(속공)에 따라 차례가 오는 턴전체 파티 일괄 계획 제출은 없앤다. 개인 차례의 이동·행동 미리보기는 유지한다(UI 절 U2: 이동 → 행동 → 대상 → 확인).
일반전은 다수 적, 보스는 이동하며 패턴 사용적 id enemy:k, 보스는 그중 한 명. 패턴 데이터에 MoveBefore/FacingRule/MoveAfter.
위치로 피할 공격은 아군 이동 결정 전에 의도 공개예고 2단계 — 전술 예고(직전 행동 종료 때 정해 아군 차례에 공개: 종류·목표·이동 예정·위험 범위, 확정은 실선 '고정'·예상은 점선)와 공격 직전 예고(적 차례의 동작·박자, 클로즈업은 강조). 이동 보스는 이동 전 위치 → 경로 → 도착·방향 → 도착 후 범위와 조준 고정 시점 표시, 추적 공격은 별도 표시. 몰래 재조준 없음.
카메라는 역동적으로, 대응 입력 중에는 안정구간 3단계 — 차례 전환·공격 준비(스윙·클로즈업·추적 허용) / 박자 읽기 시작(RESPONSE_START)~마지막 대응 입력(LAST_RESPONSE_INPUT)(위치·회전·FOV 안정, UI도 자리 고정) / 그 뒤(성공·실패 연출·흔들림·슬로·줌). 이동 보스·다수 적은 행동자·대상 현재 위치 기준 후보 계산 → 충돌·경로·가림·UI 겹침 검사 → 없으면 안전한 넓은 구도. 슬로는 연출 시간만, 게이지·판정 불변.
합동 작전·파티 릴레이 유지G·M·M+의 생성·변환·소비 관계를 그대로 옮기고 시간 단위만 새로 정한다(4절). 명시적 연결로만 소비.
기존 대응 규칙 계승누구나 패링(타격마다 Q/W/E/R/A/S/D/F 결정적 난수), 방패 수호 막기 Shift, 저스트 회피 Space, 준비 방어자가 가장 가까운 아군을 자동 엄호(비관통 대체), 측면·배후 이점, 위치 회피 불가 ≠ 저스트 회피 불가, 레이드 3단계 예외.
실제 참가자 1~5명없는 슬롯은 명령·표적·생존자·타임라인·엄호에 넣지 않는다(1인 튜토리얼에서 B~E 입력 요구 없음).
튜토리얼여주인공 1인 + 자경단원 목검 대련, 이동 → 리듬 패링 → 저스트 회피 → 위치 회피 불가·준비 방어 → 측면·배후 → 가짜 박. 적 Speed = A라 A와 적이 번갈아 온다(한 단계 = A 차례 + 적 차례).
A~E는 임시 시험 역할E의 예약 이관을 정식 캐릭터·직업 확정으로 확대하지 않는다.
전투 공간 v0.4옛 v0.3은 고정 배치 시제품 기록으로 보존. v0.4는 세 층(전투 가능/카메라 여유/배경), 전장별 배치도, 조우 유형별 시작 배치, 검증 상태 구분.
옛 기록옛 문서·5인 시제품·기록 보존. 실제 삭제는 별도 승인.

2. 규칙 절 요지(②-A, 상세는 파일)

  • 차례·게이지[계약]: 필요 틱 = max(0, ceil((1000−게이지)/TurnSpeed)). 행동자만 −1000(넘친 몫 유지, 상한 999), 비행동자 게이지 불변. 0틱 참가자가 여럿이면 시간 진행 없이 차례로. 동률 아군 → A~E → 적 id. TurnSpeed(행동 순서)와 MoveRange(이동 거리) 분리. 선택 시간·연출·슬로는 게이지·판정 불변. 예측 PredictTurns(N).
  • 효과 지속·소비(R1): 공격 지원은 다음 유효 공격 1회에 소비[확정], 만료 시점[대기]. 보호막은 피해 소진과 시간 만료 분리. 둔화·지속 피해는 적용 차례 제외, 대상 다음 차례 시작부터 차감. 속도 부작용 표(Speed 80/100/130에서 막아 주는 평균 적 차례 1.25/1.0/0.77).
  • 경직 파괴(R2): 기존 승인 '공격 하나 취소' 계승[확정] — 공격 중이면 그 공격, 아니면 다음 공격 1회. 자동 중첩 없음, 비용 한 번[계약]. 무력화 계산(5명 Speed 100·배후 타격이면 보스 차례마다 파괴 가능) → '경직 중 재누적 금지' 권고.
  • 연계(R3): G(A2 타격 모두 패링 완벽·생존 때 생성, C2 소비 +10) / M·M+(C2 생성, D2 소비 +20/+40), 명시적 연결로만 소비, 거리 8m[위임]. 만료·보유[대기]. E 예약 유지안[대기]: E 차례 행동 하나로 예약(게이지 −1000 한 번, 추가 차례 없음, 예측상 지정 적 차례가 E 다음 차례보다 먼저일 때만) → 지정 적의 차례가 끝날 때(공격 실행·취소·선사망 모두) 결정 지점을 열고 타임라인 정지 → 회복(E2)·공격 지원(E3)·대기 중 선택, E 현재 위치에서 실행·사거리·시야 재검사·비용 그때 → E 차례가 먼저 오면 그 시작에 만료, E 쓰러지면 소멸, 한 번에 하나·발동 1회, 사건 RESERVE_SET/OPEN/CHOICE/EXPIRE. 함정 대체안은 제안으로만.
  • 자동 엄호(R4): 가장 가까운 아군 자동 보호 원칙[확정], 동률 A~E 순. 강제 이동은 현행 계약(두 반지름 합 + 2cm, 막히면 제자리)을 적 공격마다 한 번. 정면 판정은 타격 순간, 집중력은 선언 때 1회, 미리보기 = 실제 함수. 대상 고정·검사 시점[대기]. COVER_TARGET 사건(assigned / out_of_range·target_down·coverer_down·cannot_act / expired)로 UI 표시 대상과 실제 보호 대상을 항상 같게.
  • 다수 적(R5): 적별 검사 + 조우 수준 검사, 위반 패턴은 건너뛰고 타임라인 불변. 조우 검사 도구가 같은 대상 집중·준비 기회 없는 연속·자원 요구를 보고. 행동 빈도 = 아군 Speed 합 ÷ 보스 Speed(모두 100이면 5배), 임의 추가 턴 없음.
  • 예고·이동 보스(R6): 표적 종류 고정 / 규칙(고정 시점까지 갱신, RETARGET 사건에 원인) / 추적(별도 고정 시점, 뒤로는 저스트 회피만). 경로는 직선·막히면 멈춤(코드 ChargeStop과 같은 기하), 미리보기 같은 해석. Approach의 StopAtRangeCm은 몸 가장자리 사이 거리. 실패해도 예정 행동 소모, 몰래 재조준 없음. 조준 고정 시점·대상 선사망·Circle[대기].
  • UI 계약(9절): PredictTurns, GetParticipants, GetEnemyRoster/State, ValidTargets, QueryCommand(사거리·시야·구역·예상 피해·치명·경직·불가 이유·예고 범위·엄호선), SubmitCommand(거부 이유), GetDisplayAnchor; 알림 TURN_START/END, TIMELINE(원인), INTENT(단계·확정/예상·경로·도착·방향·범위·표적 종류·고정 시점), RETARGET, COVER_TARGET, RESPONSE_START·LAST_RESPONSE_INPUT, ENEMY_MOVE, 적 id 붙은 피해·경직·쓰러짐, VICTORY·DEFEAT·(ESCAPE), ThreatsBefore. 표시 순번 = 조우 데이터 순서 = '적 k'. 공격 id T{차례}.{적 id}.{패턴}, 타격 .H{n}.
