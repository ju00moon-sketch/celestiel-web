3.4 사용자 결정이 필요한 것

  1. 튜토리얼 전투 방식
  • 지금 튜토리얼 전투는 반응형 전투(RT-v0.3+D8, 1명)다. 사용자 목표 '전투 로직 완성'은 전술 전투(CT-P1: 자유 이동·리듬 패링)다.
  • 준완성 튜토리얼이 새 전술 전투를 써야 하면, 공터에 전투 공간 데이터(JSON, 장애물 태그)와 1명 전술 시작 상태가 필요하다. 이는 ②-A 일이고, ⑥은 공터 배치를 한다.
  • 권장: 준완성 1차는 지금 전투를 유지한다. 전술 전투 연결은 CT-P1 검토가 끝난 뒤 따로 정한다.
  1. 튜토리얼 적 모습: 지금은 시제품 보스 블록(회색 몸통과 팔)이다. 사실풍 공터에서 크게 튄다. 적 디자인은 사용자 결정 전이라 ⑥은 바꾸지 않는다. 그대로 둘지, 적을 정할지 확인이 필요하다.
  2. 자리 표시 처리(3.3 라)
  3. Fab 유료 허용 여부: 해바라기·사이프러스·채소는 무료 후보가 없다.
  4. 외부 3D 생성 도구 크레딧 한도(4.2절)
  5. 문구: 살펴보기 3곳과 끝 화면의 '임시 문구'를 그대로 둘지. 이름·사건이 미정이라 ⑥은 보이는 것만 적은 지금 문구를 유지하길 권한다.
