1. 이 문서가 정하는 것과 정하지 않는 것

정한다(배치 기획안)정하지 않는다(제안으로만 적거나 비워 둠)
위치, 크기, 길과 구역, 랜드마크·시선 유도, 조명, 전투 공간의 자리와 방향, 살펴보기·트리거 자리 표시, 필요한 모델·컨셉 장면 목록이야기(주인공이 왜 여기 있는지), '이세계로 떨어진 느낌'을 쓸지(Q5 검토 중), 동료 합류, 튜토리얼 전투 인원과 적, 살펴보기 문구, 상호작용 키, 합류·영입 시스템(만들지 않음)
  • 세계관 조건
  • 주인공은 평범한 인간으로 시작한다(W03).
  • 첫 튜토리얼에 자율 병기나 특별한 능력을 미리 넣지 않는다(W03 이하).
  • 튜토리얼 첫 장면에서 5인을 한꺼번에 소개한다는 뜻은 아니다(설계 갱신 v0.2).
  • 그래서 시작 자리의 선돌 둘레는 성격을 정하지 않은 오래된 돌로 둔다. 특정 유적(킨네리아 등)과 연결하지 않는다.
  • 이름: 작업용 이름만 쓴다(Q9). 이정표 판과 선돌에는 글자·문양을 넣지 않는다.

2. 위치: 캄포 비에호 남쪽 들판

  • 좌표를 캄포 비에호와 같이 쓴다(원점 = 마을 우물, +X 북, +Y 동). 튜토리얼 지역은 마을 남쪽 경계(X −8000) 아래 X −25000~−8000, Y −4400~3600이다. 나중에 두 맵을 한 월드로 이어 붙여도 좌표를 바꿀 필요가 없다.
  • 출구가 마을의 시작 위치로 이어진다. 튜토리얼 길의 끝(−8000, −600)은 캄포 비에호 남쪽 입구 길 R_S의 시작점이자 출구 EX_S 자리다. 그래서 튜토리얼을 마치면 Q11의 '남쪽 입구 길에서 시작'과 같은 자리에서 마을로 들어간다.
  • '떨어진 느낌'과의 관계: 시작 자리는 흙둑으로 둘러싼 작은 분지 안의 오래된 선돌 둘레다.
  • '어딘가에서 떨어져 깨어난 자리'로도, '마을 사람이 새벽 들판에 나온 자리'로도 쓸 수 있게 중립으로 둔다.
  • 사용자가 Q5를 정하면 연출(빛·소리·자국)만 더하면 되고 배치는 그대로다.
  • 맵: 별도 맵 /Game/Maps/L_Tutorial_Blockout. 마을로 넘어가는 출구는 캄포 비에호처럼 트리거와 이름표만 두고 기능은 없다(Q8 방식).

6. 해 뜰 녘 조명

  • 캄포 비에호와 같다(Q3).
  • 주광 (Pitch −12, Yaw −154). 해는 방위 26°, 고도 12°다.
  • 노출 EV100 1.5 고정, 하늘빛 3.0.
  • 튜토리얼에서 마을로 걸어 들어갈 때 빛이 바뀌지 않는다.
  • 높이 안개: 대응 시점에서 팔 뒤로 지나가는 먼 언덕 윤곽을 흐리게 하려는 것이다(7장). 시작 거리 60m, 밀도 0.02에서 시작한다. L_BattleTest 값(0.05)은 200m 넘게 떨어진 마을 원경(목표)까지 지울 수 있어 낮췄고, 캡처로 조정한다.
  • 전투 방향과 해: 무대를 Yaw 251°(보스가 서남서)로 놓았다.
  • 해가 무대 기준 135°(파티 오른쪽 뒤)에서 온다. L_BattleTest의 주광 관계(135°)와 같아, 보스 앞면이 밝고 팔 움직임이 읽힌다.
  • 다만 해가 낮아(12°) 그림자가 길게 보스 왼쪽 앞으로 눕는다. 캡처에서 판독을 확인한다.

#장면보여 줄 것넣지 않을 것
1시작 분지의 첫 화면(KeyView_Start 구도)해 뜰 녘, 흙둑으로 둘러싼 작은 분지 안의 오래된 선돌 둘레, 가운데 선 인물(뒷모습), 열린 북쪽 너머 낮은 언덕 위 외딴 큰 나무와 멀리 마을 종루 실루엣, 오른쪽 앞에서 낮게 뜨는 해글자·문양, 특정 유적이나 마법 흔적, 괴물
2전투 공터(KeyView_Default 구도)파티 뒤쪽 높은 곳에서 서남서를 본 풀밭 공터, 둘레의 무너진 낮은 돌담, 파티 자리 다섯(인물은 실루엣이나 비워도 됨), 공터 끝의 적 자리(적 모습은 미정이라 비우거나 흐린 형체), 오른쪽 뒤에서 드는 낮은 해와 긴 그림자, 뒤쪽 낮은 숲 능선(가운데는 트임)특정 적 디자인, 전투 UI
3개울 다리와 울타리 문(KeyView_Exit 구도)나무 다리 위에서 북쪽, 산울타리의 열린 문, 그 너머 캄포 비에호 남쪽 입구 길과 마을(기존 전경 컨셉과 같은 마을로 보이게)마을 사람·사건 암시

11.1 2단계 실행 결과(2026-09-26, UE 5.8.3, 주 폴더 c0424c9)

  • create: 오류 0, 물체 322개, 탐험 게임 모드 연결(33초). 시작 Yaw를 8°로 바꾼 뒤 다시 만들어도 오류 0이다.
  • verify(새 프로세스): 20/20, 종료 코드 0(두 번 모두).
  • 확인 항목: 회전 물체를 포함한 모든 외부 3D 생성 도구의 중심·크기·방향, 모델 태그 1~8, 무대 로컬 값 = l_battletest_spec, 확인용 카메라, 트리거 5개, 조명·노출·안개, 길 윗면 높이 57점.
  • walk(PIE, 143초): 7/7 기대대로.
  • T01은 157m를 30.9초에 걸었다(500cm/s). T02·T03·T07은 모든 점에 도착하고 문제 0이다.
  • T04 개울, T05 산울타리, T06 흙둑은 벽 면에서 캡슐 반지름(42cm) 앞에서 stuck으로 멈췄다.
  • 시작 방향(총괄 요청 a)
  • Yaw 0에서는 캡슐이 먼 마을 가운데(예배당·종루)를 가렸다.
  • Yaw 8에서는 마을 전체가 캐릭터 왼쪽에 보이고 길이 그쪽으로 이어진다. PlayerStart Yaw 8°로 정했다(레벨만 바꿈).
  • 카메라를 −15°로 내려다보게 하면 마을이 머리 위로 올라와 가장 잘 보이지만, 시작 카메라 Pitch는 PlayerStart로 정할 수 없고 탐험 캐릭터 코드가 필요하다. ②-B 선택 사항으로 남긴다.
  • 긴 그림자·안개(총괄 요청 b)
  • 해 고도 12°라 인물·나무 그림자가 카메라 쪽으로 길게 눕는다. 길 판독에는 방해가 없다.
  • 분지는 흙둑 그림자가 넓게 드리우지만 선돌은 밝다.
  • 전투 공터는 언덕·나무 그림자 밖이라 해가 든다. 보스 뒤 가운데는 비어 있고, 먼 숲은 좌우 끝에만 있다.
  • 안개 0.02에서 팔 뒤 먼 언덕은 낮은 대비의 흙빛 덩어리로 보이고, 마을 원경(200m 넘음)은 뚜렷하게 남는다.
  • 무대 표식은 게임에서 숨겨 보스·5인에 드는 그림자는 이번 캡처로 볼 수 없다. 전투 연결 때 확인한다.
  • 캡처(`Celestiel/(내부 경로))
  • 에디터: captures/(CAM_Default_Tut, CAM_React_Tut, Top, Start_High, Clearing_From_Path, Exit_From_Bridge, editor_sheet).
  • 3인칭: walk/captures/.
  • 스폰, 시작 변형 3장, 외딴 나무, 공터 입구, 다리, 문(마을 경계).
  • TP_sheet, TP_Start_yaw0_vs_yaw8, 확대 비교 그림.
  • 첫 실행(Yaw 0) 결과는 walk_run1_yaw0/.
  • 참고: 작업용 ID 이름표(TUT_BattleStart, EXM_*, EX_N)가 PIE에서 먼 곳에 떠 보인다.
  • 총괄 승인(2026-09-26): 게임에서 숨긴다. 다음에 맵을 다시 만들 때(실제 모델 교체 등) 함께 넣는다. 지금은 따로 실행하지 않는다.
  • 저장소 파일은 ③ CP-LVL03 검토 중이라 그때 바꾼다.
  • 시작 카메라 Pitch −15°: 선택 제안으로 기록만 한다(②-B 몫, 지금은 하지 않음).
  • 실제 모델(Model:1~8): 총괄이 사실풍으로 다시 만드는 중이다. 내려받기 허락과 ④ 정리가 끝나면 교체를 배정받는다.
