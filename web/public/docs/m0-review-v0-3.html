턴제 RPG 전투 시제품 — 총괄 검토 추가본 v0.3

  • 작성: 2026-09-24, ① 총괄
  • 기준: GDD v0.1, 세계관 메모 v0.1, 설계 갱신 v0.2, 사용자 회신 3차(DECISIONS.md)
  • 관계: v0.1·v0.2 검토를 대체하지 않는다. 이 문서는 N1~N3 정의, MCP 사용 기록, 남은 승인 항목만 다룬다.

1. N1~N3 정의

세 항목 모두 전투 규칙(R1~R10)과 수치를 바꾸지 않는다. 미결정이어도 M1 규칙 엔진은 진행할 수 있게 만든다: 표시 이름은 데이터 한 곳에서 관리하고, 시험 설정은 데이터 행으로 추가하며, 기록은 전투 로그 위에 얹는 집계로 만든다.

N1. 시제품 화면의 표시 용어

  • 결정할 것: ① 임시 5인의 화면 표시 이름 ② 연계 효과 3종의 표시 이름 ③ 연계 기능을 화면에서 부르는 말. 내부 데이터 ID(예: Char.A, Effect.A)는 이 결정과 무관하게 고정한다.
  • 권장안: 인물 A 수호·B 변환·C 사격·D 마무리·E 지원(GDD v0.1 임시명), 효과 충격·번개·전하, 기능 이름 연계. 화면 한쪽에 "시제품 임시 표기" 안내를 한 번 표시한다.
  • 대안 1: 인물 A~E, 효과 효과 A·B·C만 표시. C04(표현 보류)와 가장 거리가 멀다. 대신 사용자가 불발 이유를 설명할 수 있는지 보는 이해도 시험(QA09)에서 기억 부담이 커져, 결과가 규칙보다 표기 탓으로 나빠질 수 있다.
  • 대안 2: v0.2 추천 포지션명(수호자·검사·술사·사수·치유사) 사용. 확정되지 않은 직업을 확정처럼 보이게 하므로 권하지 않는다.
  • 영향: 규칙 영향 없음. 작업은 표시 이름 표 1개와 UI·아이콘(M2-4·M2-5)에만 닿는다. 결정 전까지 M2-5 아이콘 제작만 기다리고 나머지는 진행된다.

N2. 시험 C1~C5 — 한 명이 빠진 상태의 시험

  • 결정할 것: 시험 설정에 "시작부터 한 명이 전투불능"인 다섯 가지를 추가할지와 무엇을 볼지.
  • 권장안: 시험 A 초기 상태에서 A~E 중 한 명씩 전투불능으로 시작하는 C1~C5를 추가한다. 자동 시험은 설정마다 "T01·T02 각각에 쓸 수 있는 대응(방해·방어·회복) 수단이 남는가", "역할별로 기본 행동 외 선택지가 있는가"를 기록한다. 합격·불합격이 아니라 관찰 결과로 보고한다. 사용자 플레이는 연계 경로가 끊기는 C2(B 부재)·C3(C 부재)만 권한다.
  • 대안 1: 추가하지 않는다. v0.2 8장의 질문("한 명의 부재가 모든 행동을 무효로 만드는가")은 사용자 플레이에서 우연히 생길 때만 확인된다.
  • 대안 2: 자동 시험만 하고 사용자 플레이는 하지 않는다.
  • 영향: 규칙 영향 없음(시작 상태 데이터 5줄). 시작부터 전투불능인 인물에게 명령을 못 넣게 하는 처리는 R5·P08 때문에 어차피 필요하다. 작업량은 M1 자동 시험 5개 정도다.

N3. 역할별 선택 기록

  • 결정할 것: 전투가 끝날 때 무엇을 요약해 어디에 남길지.
  • 권장안: 전투마다 역할별 스킬 선택 횟수, 쓰지 않은 스킬, 연계 길이, 라운드별 계획 시간·명령 수정 횟수, 패배 원인을 요약해 로컬 파일((내부 경로), 기계용 JSON + 사람이 읽는 텍스트)로 남긴다. 외부 전송은 없다.
  • 대안 1: 결과 화면에만 보여 주고 파일로 남기지 않는다. 시험 간 비교가 어렵다.
  • 대안 2: 기록하지 않고 GDD 10장 관찰 항목을 사람이 적는다.
  • 영향: 규칙 영향 없음. 선택 횟수·연계 길이는 M1 로그 집계로, 계획 시간·수정 횟수는 M2 UI 이벤트로 만든다. 개인정보나 외부 전송은 없다.

  • 신규 설치·외부 접속·유료 서비스: 없다. Unreal MCP는 엔진에 들어 있는 플러그인을 켜는 것이고 루프백으로만 접속한다.
  • 따로 승인이 필요한 부분(현재 하지 않음): 개발 세션 세션(③·⑤)에서 MCP를 쓰려면 개발 세션 계정 설정 파일(config.toml)을 고쳐야 하고, 이 설정은 OpenTalk의 개발 세션 세션에도 적용된다. 전역 설정 변경에 해당하므로 등록하지 않는다. 시제품은 개발 세션 세션(②·④·⑥)만 MCP를 쓰고, ③·⑤는 커맨드릿·자동 시험으로 작업한다.
